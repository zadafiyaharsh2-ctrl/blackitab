# RANKLEN - Comprehensive Platform Architecture & Logic Documentation

This document outlines the core logic, algorithms, UI patterns, and data flows that power the RANKLEN application. It serves as a technical reference for future expansions and maintenance.

## 1. Core Analytics & Event Architecture
The heart of RANKLEN is the **Submission & Strategy Engine**. Every action a user takes—completing a theory topic, attempting an exam question, or viewing a leaderboard—generates analytical events.

### The Gamification Algorithm (Streak & XP)
- **XP Calculation**: Points are dynamically generated based on the `difficulty` of the `ExamQuestion` solved combined with the `timeTakenSeconds` compared to the global `averageSolveTimeMs`.
- **Streak Evaluation**: Tracked dynamically. A daily cron job inspects the `Attempt` timestamp to maintain or break the `currentStreak`, while `longestStreak` acts as the all-time high water mark.

## 2. Dynamic Routing & Contextual Navigation
The platform integrates advanced routing techniques:
- **Main View vs Focus Mode**: In `ExamQuestions.jsx`, the standard grid layout smoothly transitions into an immersive `focusMode` leveraging Framer Motion `AnimatePresence`. 
- **Protected Routes**: Implemented in `App.jsx`, ensuring that unauthenticated users are seamlessly redirected to the landing/login view.

## 3. Intelligent Fallback Data Pattern (Zero Blank State Architecture)
A primary frontend architecture principle is that **a page must never look broken**. If the backend API routes return empty arrays (e.g., a fresh DB deployment), the frontend catches this and injects rich, realistic Dummy Data.

### Implementations:
- **Theory (`Theory.jsx`)**: If `/api/subjects` or `/api/topics` fails, the `mockTheoryData.js` injector supplies extensive structures encompassing DBMS, OS, and Data Structures, formatted with rich ReactMarkdown blocks (Code, Images, Lists).
- **Leaderboard (`Leaderboard.jsx`)**: Injects competitive profiles containing realistic names, XP, streaks, and generated avatar URLs to prevent an empty podium.
- **Exam Engine (`ExamQuestions.jsx`)**: Injects deep CSE technical questions involving hash collisions, network addressing, and process synchronization if the `/:examId` returns 0 questions.

## 4. UI/UX: Premium Glassmorphism & Framer Motion
Every auxiliary page has been overhauled strictly avoiding generic placeholders:
- **Glassmorphic Panes**: Utilizing Tailwind's `bg-black/40 backdrop-blur-md` mixed with subtle `border-white/10` to create deep, translucent elements.
- **Staggered Animations**: Utilizing Framer Motion `containerVariants` to load lists organically.
- **Orbits & Backgrounds**: Utilizing absolute position blurred divs (`blur-3xl bg-blue-500/10`) to provide deep vibrant color without distracting from the main text.

## 5. Auxiliary Platforms
The application has been audited to ensure all secondary paths act fully realized:
- **Store (`Store.jsx`)**: Features AI Personalized laptop/book matching based on student activity.
- **Career Launchpad (`Jobs.jsx`)**: Intelligent tracking that suggests an auto-generating Resume.
- **Revenue Dashboard (`Earnings.jsx`)**: Mock real-time transaction ledgers and financial CSV exports.

## 6. Contextual Global Toasts
Instead of standard alert modals, the system utilizes `react-hot-toast` to inject custom success/error rendering to match the distinct styling of the app. This is explicitly tied into authentication, question submits, and user network additions.
